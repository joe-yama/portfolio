# Proposal

## Why

トップページ本文のサイト内の導線（Photos / Career / 言語切り替え）にはドット絵アイコンが付いたが、全ページ共通のヘッダーの常設ナビには付いていない（`fix-misc` の申し送り）。同じ行き先のリンクで意匠が揃わないので、ヘッダーにも同じアイコンを付ける（PO 承認 2026-09-23）。あわせて、同じ部品（導線とアイコンの対応づけ）に触る申し送りの Minor を片付ける。

## What Changes

- ヘッダーの「Photos」「Career」「言語切り替え」の文字の左に、トップページ本文と同じドット絵（カメラ / 鞄 / 地球儀）を小さく添える（PO 決定 2026-09-23: トップ本文と同じ 16px、文字の高さに収め、ヘッダーは 1 行を保つ）。幅 30rem（480px）未満の画面ではヘッダーのアイコンを隠す（PO 決定 2026-09-23、実装中に判明: アイコンを付けると 1 行に収まる最小の画面幅が約 378px から約 443px に広がり、390〜430px の端末でヘッダーが 2 行になるため）。ロゴ（名前）にはアイコンを付けない。アイコンは装飾として支援技術から隠す
- 導線とアイコンの対応を、配列の位置どうしの突き合わせ（`pairByIndex`）ではなく、導線のデータそのものに持たせる。トップページとヘッダーが同じ対応を使う（`icon-refresh` 申し送り 3、ponytail）
- トップページの導線アイコンの e2e 検査を、並び順ではなくリンク先（`href`）と結びつけて比べる（`icon-refresh` 申し送り 2）
- `ui` の `careerSections` の型を、区画の一覧から導く（Change 4 の ponytail）

**含めない**: 375×667 で写真が本文幅より狭くなる件（PO 決定 2026-09-23: 直さない）、ヘッダーの余白の詰め直し、404 ページのヘッダー（ナビを出さないので対象外）、アイコンの図柄の変更。

## Capabilities

### New Capabilities

なし

### Modified Capabilities

- `layout-shell`: ヘッダーの要求に「Photos / Career / 言語切り替えの各リンクに、トップページ本文の導線と同じドット絵アイコンを添える」を足す

## Impact

- `src/components/Header.astro`、`src/pages/[lang]/index.astro`、`src/lib/site.ts`
- `tests/unit/site.test.ts`（`pairByIndex` のテストを消し、導線がアイコンを持つことのテストに置き換える）、`tests/e2e/links.spec.ts`（ヘッダーのアイコンと、href に結びつけた比較）
- 見た目: 全ページのヘッダーのナビにアイコンが付く。ヘッダーの高さは変えない
