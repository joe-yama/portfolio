## MODIFIED Requirements

### Requirement: トップページのサイト内の導線

`/ja/` と `/en/` のトップページは、本文に次の 3 つをこの順で持たなければならない（MUST）: そのロケールの写真一覧 `/photos/` へのリンク、そのロケールの経歴 `/career/` へのリンク、言語切り替え。言語切り替えは、ヘッダーの言語切り替えと同じ形（`JA / EN` の並び、表示中のロケールはリンクにしない、もう一方は他言語版のトップへのリンク、グループとしての名前）でなければならない（MUST）。ヘッダーに同じ行き先のリンクがあってよい。写真一覧と経歴のリンクはそれぞれ文字の前に、言語切り替えはまとまりの先頭に、ドット絵アイコンを 1 つずつ表示しなければならない（MUST）。本文の言語切り替えには区切り線を付けない。

#### Scenario: 日本語トップの導線

- **WHEN** `/ja/` を表示する
- **THEN** 本文に `/ja/photos/` へのリンク、`/ja/career/` へのリンク、言語切り替えがこの順で、それぞれドット絵アイコン付きで現れる。言語切り替えは `JA / EN` を表示し、`JA` はリンクでなく `aria-current="true"` を持ち、`EN` は `/en/` へリンクする

#### Scenario: 英語トップの導線

- **WHEN** `/en/` を表示する
- **THEN** 本文に `/en/photos/` へのリンク、`/en/career/` へのリンク、言語切り替えがこの順で、それぞれドット絵アイコン付きで現れる。言語切り替えは `JA / EN` を表示し、`EN` はリンクでなく `aria-current="true"` を持ち、`JA` は `/ja/` へリンクする
