# Spec Delta

## MODIFIED Requirements

### Requirement: ビルド出力のブラウザ検査

`pnpm e2e` は、ビルド出力を静的に配信した状態でブラウザから検査しなければならない（MUST）。検査は少なくとも次を含まなければならない（MUST）: すべての種類のページ（トップ、ギャラリー、写真の個別ページ、経歴、404）が両ロケールで表示されること、各ページの `<html lang>` が URL のロケールと一致すること、`link[rel=alternate][hreflang]` が 3 本あること、言語切り替えが同じページの他言語版へ遷移すること、写真が `<picture>` として出力されていること、ページが外部ホストへリクエストを行わないこと、アクセシビリティの自動検査で違反が 0 件であること。

外部ホストへのリクエストの検査は、上記のすべての種類のページを両ロケールで対象にしなければならない（MUST）。一部のページだけを対象にしてはならない（MUST NOT）。

`pnpm e2e` は、検査対象がこのリポジトリのビルド出力であることを保証しなければならない（MUST）。配信サーバが検査の開始前から動いている場合、別のビルド出力を検査してしまう可能性があるため、検査を開始せずに非 0 で終了し、その理由と対処を示さなければならない（MUST）。検査の終了時に停止してよいのは、自身が起動した配信サーバだけとする（MUST）。

#### Scenario: すべてのページの表示

- **WHEN** `pnpm e2e` を実行する
- **THEN** 5 種類 × 2 言語のページと 404 ページが表示され、いずれも失敗しない

#### Scenario: アクセシビリティ違反

- **WHEN** いずれかのページにアクセシビリティ違反を持つ要素を追加して `pnpm e2e` を実行する
- **THEN** 終了コードは非 0 になる

#### Scenario: 外部ホストへのリクエスト

- **WHEN** e2e が上記すべての種類のページを両ロケールで開いている間のネットワーク要求を集める
- **THEN** 配信元以外のホストへの要求は 0 件である

#### Scenario: 配信サーバが既に動いている

- **WHEN** 別のディレクトリの配信サーバが動いている状態で `pnpm e2e` を実行する
- **THEN** 検査は開始されず、終了コードは非 0 で、既に動いている配信サーバを止めるよう示される
- **AND** その配信サーバは止められない
