# Spec Delta

## ADDED Requirements

### Requirement: 特許の外部リンクの言語

特許の `url` が言語ごとの表示を持つ外部サイトを指す場合、日本語のページからは日本語の表示を、英語のページからは英語の表示を指さなければならない（MUST）。同じ特許に対して、日本語のページと英語のページが同一の URL を指してはならない（MUST NOT）。

#### Scenario: 日本語のページのリンク先

- **WHEN** `/ja/career/` の特許の名称のリンクをたどる
- **THEN** リンク先は日本語の表示を指す URL である

#### Scenario: 英語のページのリンク先

- **WHEN** `/en/career/` で同じ特許の名称のリンクをたどる
- **THEN** リンク先は英語の表示を指す URL であり、日本語のページのリンク先とは異なる
