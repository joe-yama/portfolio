# Spec Delta

## MODIFIED Requirements

### Requirement: ビルド出力のブラウザ検査

`pnpm e2e` は、ビルド出力を静的に配信した状態でブラウザから検査しなければならない（MUST）。検査は少なくとも次を含まなければならない（MUST）: すべての種類のページ（トップ、ギャラリー、写真の個別ページ、経歴、404）が両ロケールで表示されること、各ページの `<html lang>` が URL のロケールと一致すること、`link[rel=alternate][hreflang]` が 3 本あること、言語切り替えが同じページの他言語版へ遷移すること、写真が `<picture>` として出力されていること、ページが外部ホストへリクエストを行わないこと、アクセシビリティの自動検査で違反が 0 件であること、複数の画面サイズでの表示に関する次の 3 点。

- トップページと写真の個別ページで、初見表示の要求（スクロールせずに見えるべき要素）が満たされること。検査は少なくとも幅 1280px・高さ 720px と幅 1440px・高さ 900px の 2 つの画面サイズを両ロケールで含む
- トップページと写真の個別ページの写真の表示上の縦横比が、元画像の縦横比と一致すること
- ギャラリー一覧のサムネイルの表示幅が、グリッドの列の幅と一致すること

外部ホストへのリクエストの検査は、上記のすべての種類のページを両ロケールで対象にしなければならない（MUST）。一部のページだけを対象にしてはならない（MUST NOT）。

`pnpm e2e` は、検査対象がこのリポジトリのビルド出力であることを保証しなければならない（MUST）。配信サーバが検査の開始前から動いている場合、別のビルド出力を検査してしまう可能性があるため、検査を開始せずに非 0 で終了し、その理由と対処を示さなければならない（MUST）。検査の終了時に停止してよいのは、自身が起動した配信サーバだけとする（MUST）。

#### Scenario: すべてのページの表示

- **WHEN** `pnpm e2e` を実行する
- **THEN** 5 種類 × 2 言語のページと 404 ページが表示され、いずれも失敗しない

#### Scenario: アクセシビリティ違反

- **WHEN** いずれかのページにアクセシビリティ違反を持つ要素を追加して `pnpm e2e` を実行する
- **THEN** 終了コードは非 0 になる

#### Scenario: 外部ホストへのリクエスト

- **WHEN** e2e が上記すべての種類のページを両ロケールで開いている間のネットワーク要求を集める
- **THEN** 配信元以外のホストへの要求は 0 件である

#### Scenario: 初見表示が破れる

- **WHEN** 写真の表示高さの上限を取り除いて `pnpm e2e` を実行する
- **THEN** 終了コードは非 0 になり、画面の下端より下にある要素が報告される

#### Scenario: 写真が歪む

- **WHEN** 写真の表示に、縦横比を保たない高さの指定を加えて `pnpm e2e` を実行する
- **THEN** 終了コードは非 0 になる

#### Scenario: サムネイルが列幅を満たさなくなる

- **WHEN** ギャラリーのサムネイルが列の幅いっぱいに広がらない状態にして `pnpm e2e` を実行する
- **THEN** 終了コードは非 0 になる

#### Scenario: 配信サーバが既に動いている

- **WHEN** 別のディレクトリの配信サーバが動いている状態で `pnpm e2e` を実行する
- **THEN** 検査は開始されず、終了コードは非 0 で、既に動いている配信サーバを止めるよう示される
- **AND** その配信サーバは止められない
