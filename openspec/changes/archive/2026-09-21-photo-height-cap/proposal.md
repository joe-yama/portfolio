# Proposal

## Why

トップページを開くと代表写真だけで画面が埋まり、サイトの主（名前）も肩書も連絡先リンクも、スクロールしないと現れない。訪問者（採用担当・転職エージェント）にとって「何のためのサイトか」が第一画面で分からず、名刺としての役目を果たしていない。写真の個別ページも同じ原因で、縦位置の写真が画面 2 枚分の高さになり、タイトル・撮影地・撮影情報が画面外に出ている。

実測（1440×900、ヘッダー 65px）: トップは代表写真が 1248×832px で画面下端を超え、名前は y 1041、連絡先リンクは y 1163。個別ページ（縦位置写真）は写真が 1248×1872px で、タイトルは y 1985、撮影情報は y 2067。

## What Changes

- トップの代表写真と写真の個別ページの写真に、画面の高さに応じた**表示高さの上限**を設ける。上限にかかった写真は**縦横比を保ったまま縮小**し、切り取らない
- トップページは、代表写真・名前・肩書・連絡先リンク・サイト内の導線が、1280×720 以上の画面でスクロールなしに収まる
- 写真の個別ページは、写真・タイトル・撮影地・撮影日・撮影情報が、1280×720 以上の画面でスクロールなしに収まる
- ギャラリー一覧のサムネイルは**対象外**。現在の「列幅いっぱい」の表示を変えない
- `pnpm e2e` に上記の回帰検査（初見表示・縦横比・サムネイルの列幅）を追加する

非目標: 画像の生成幅と `sizes` 属性の見直し、ヘッダーや本文の余白の詰め直し、写真の切り取り（トリミング）表示。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `photo-pipeline`: 写真の表示に「高さの上限」と「縦横比を保つ（切り取らない）」の要求を追加し、個別ページの要求に初見表示の条件を追加する
- `profile-and-career`: トップページの連絡先リンクと導線に、初見表示（スクロールなしで見える）の条件を追加する
- `quality-gates`: `pnpm e2e` が必ず含む検査に、初見表示・縦横比・サムネイルの列幅を追加する

## Impact

- `src/components/PhotoPicture.astro`: `full` 変種の画像に高さ上限の CSS を追加（`grid` 変種は変更しない）
- `src/pages/[lang]/index.astro`: 代表写真の高さ上限の値を渡す
- `src/pages/[lang]/photos/[slug].astro`: 個別ページの写真の高さ上限の値を渡す
- `tests/e2e/`: 初見表示と縦横比の検査を追加
- 依存の追加・削除は無い。配信 JavaScript も増えない（CSS のみ）
